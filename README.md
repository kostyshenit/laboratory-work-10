## Виконані завдання
- **Задача 1 (`Task1.cpp`):** масив $4 \times 3$, кількість парних чисел у кожному рядку.
- **Задача 2 (`Task2.cpp`):** масив $6 \times 4$, кількість парних чисел у кожному стовпчику.
- **Задача 3 (`Task3.cpp`):** масив $5 \times 7$, сума елементів кожного рядка.
- **Задача 4 (`Task4.cpp`):** масив $4 \times 6$, сума елементів кожного стовпчика.
- **Задача 5 (`Task5.cpp`):** масив $3 \times 4$, максимальний елемент та його індекси.
- **Задача 6 (`Task6.cpp`):** масив $4 \times 7$, мінімальний елемент та його індекси.
- **Задача 15 (`Task15.cpp`):** масив $3 \times 3$, сума елементів по головній та побічній діагоналях.
